# User Management API

**[User Management API – Documentation](https://ddurant94.github.io/Coursera-User-Management-API/)**

A RESTful CRUD API built with **ASP.NET Core (.NET 10)** for managing users within a company.  
Features: in-memory storage, input validation, pagination, thread-safe concurrency, custom middleware, Bearer token authentication, and a full unit test suite (43 tests).

## User Model

| Field      | Type   | Required | Rules                                    |
|------------|--------|----------|------------------------------------------|
| `id`       | int    | —        | Auto-assigned, omitted from request body |
| `userName` | string | Yes      | 2–100 characters                         |
| `email`    | string | Yes      | Valid email format, max 200 characters   |

## Endpoints

All endpoints are prefixed with `/api/users`.

| Method   | Path              | Auth | Description                              |
|----------|-------------------|------|------------------------------------------|
| `GET`    | `/api/users`      | Yes  | List all users (paginated)               |
| `GET`    | `/api/users/{id}` | Yes  | Get a single user by ID                  |
| `POST`   | `/api/users`      | Yes  | Create a new user                        |
| `PUT`    | `/api/users/{id}` | Yes  | Replace an existing user                 |
| `DELETE` | `/api/users/{id}` | Yes  | Delete a user                            |

## Authentication

Every request must include a `Bearer` token in the `Authorization` header.

```
Authorization: Bearer <your-token>
```

The token is validated against the `AUTH_TOKEN` environment variable loaded from your `.env` file.

### Quick-start test token

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` and set:
   ```
   AUTH_TOKEN=test-token-abc123
   ```
3. Use that same value in every request header:
   ```
   Authorization: Bearer test-token-abc123
   ```

> `/swagger` is excluded from auth so the interactive docs are always accessible.

## Pagination

`GET /api/users` supports optional query parameters:

| Parameter  | Default | Max | Description              |
|------------|---------|-----|--------------------------|
| `page`     | `1`     | —   | Page number (1-based)    |
| `pageSize` | `20`    | `100` | Results per page       |

```
GET /api/users?page=2&pageSize=10
```

Results are always returned in ascending `id` order for stable paging.

## Getting Started

### Prerequisites
- [.NET 10 SDK](https://dotnet.microsoft.com/download)

### Setup

```bash
# 1. Clone the repo and navigate to the project folder
cd UserManagementAPI

# 2. Create your .env file from the example
cp .env.example .env
# Then open .env and set: AUTH_TOKEN=test-token-abc123
```

### Run the API

```bash
dotnet run
```

The API starts at `http://localhost:5075`.  
Open `http://localhost:5075/swagger` for the interactive Swagger UI.

## Example Requests & Responses

### Create a user

**Request**
```http
POST /api/users
Authorization: Bearer test-token-abc123
Content-Type: application/json

{
  "userName": "Jane Doe",
  "email": "jane@example.com"
}
```

**Response** `201 Created`
```json
{
  "id": 1,
  "userName": "Jane Doe",
  "email": "jane@example.com"
}
```

### Get all users

**Request**
```http
GET /api/users?page=1&pageSize=5
Authorization: Bearer test-token-abc123
```

**Response** `200 OK`
```json
[
  { "id": 1, "userName": "Jane Doe", "email": "jane@example.com" }
]
```

### Update a user

**Request**
```http
PUT /api/users/1
Authorization: Bearer test-token-abc123
Content-Type: application/json

{
  "userName": "Jane Smith",
  "email": "jsmith@example.com"
}
```

**Response** `204 No Content`

### Delete a user

**Request**
```http
DELETE /api/users/1
Authorization: Bearer test-token-abc123
```

**Response** `204 No Content`

## Error Responses

| Status | Meaning                                           |
|--------|---------------------------------------------------|
| `400`  | Validation failed — check field rules             |
| `401`  | Missing, malformed, or incorrect `Authorization` header |
| `404`  | User with the given `id` does not exist           |
| `500`  | Unexpected server error (details logged to console) |

**Validation error (`400`)**
```json
{
  "errors": {
    "Email": ["The Email field is not a valid e-mail address."]
  }
}
```

**Auth error (`401`)**
```json
{ "error": "Unauthorized. Provide a valid Bearer token." }
```

**Not found (`404`)**
```json
{ "error": "User with id 99 was not found." }
```

**Server error (`500`)**
```json
{ "error": "Internal server error." }
```
